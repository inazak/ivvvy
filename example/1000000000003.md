## 番号なしリスト（箇条書き）

- 項目 A
- 項目 B
- 項目 C

ハイフンの代わりにアスタリスクやプラスも使えます：

* りんご
* みかん
* ぶどう

+ 春
+ 夏
+ 秋
+ 冬

---

## 番号付きリスト（順序リスト）

1. 最初の手順
2. 次の手順
3. さらに次の手順
4. 最後の手順

番号は実際の数値に関わらず、連番で出力されます：

1. 第一項
1. 第二項（すべて 1. でも連番になる）
1. 第三項

---

## ネストしたリスト

- 大分類 A
  - 中分類 A-1
    - 小分類 A-1-a
    - 小分類 A-1-b
  - 中分類 A-2
- 大分類 B
  - 中分類 B-1
- 大分類 C

番号付きリストのネスト：

1. 第一章
   1. 第一節
   2. 第二節
      1. 第一項
      2. 第二項
2. 第二章
   1. 第一節

---

## 番号なしと番号付きの混在

- 準備物
  1. 材料を揃える
  2. 道具を用意する
- 手順
  1. 下準備をする
  2. 本作業を進める
  3. 仕上げをする
- 確認
  1. 結果を検証する

---

## タスクリスト（GFM 拡張）

- [x] 完了済みのタスク
- [x] これも完了
- [ ] 未完了のタスク
- [ ] こちらも未完了

ネストしたタスクリスト：

- [x] フェーズ 1
  - [x] 設計
  - [x] 実装
  - [x] テスト
- [ ] フェーズ 2
  - [x] 設計
  - [ ] 実装
  - [ ] テスト
- [ ] フェーズ 3
  - [ ] 設計
  - [ ] 実装
  - [ ] テスト

---

## リスト内の複数段落

- 最初の項目

  この項目には複数の段落があります。インデントを揃えることで
  同じリスト項目に属する段落として扱われます。

- 次の項目

  こちらにも追加の段落があります。
