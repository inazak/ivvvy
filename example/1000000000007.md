## 基本的な WikiLink

`[[ページID]]` の形式でページ間リンクを作成できます。

このページへのリンク例（サンプル一覧）：[[1000000000001]]

クリックすると対応するページに遷移します。存在しないIDの場合は新規作成画面に
リダイレクトされ、IDがタイトルの初期値として入力された状態になります。

## キーワード WikiLink の仕組み

ivvvy では、ページIDと表示キーワードを分離して管理しています。

**キーワードで書く → 後からIDが自動接続される** というフローです：

1. 本文に `[[Go言語]]` のようにキーワードで WikiLink を書く
2. 未解決リンクをクリックすると新規作成画面にリダイレクト
3. 「Go言語」というタイトルのページを作成・保存
4. 保存時に全ページを走査し、`[[Go言語]]` を `[[新しいID|Go言語]]` に自動書き換え

> [!info] 設計の意図
> ページID（ミリ秒タイムスタンプ）とキーワード（人間が読む名前）を
> 完全に分離することで、タイトル変更時も既存リンクが壊れない設計になっています。

## 普通のリンクとの比較

Markdown の通常のリンクと WikiLink を比較します：

**通常の Markdown リンク：**
[GitHub](https://github.com) — 外部URLへのリンク

**WikiLink（IDそのまま）：**
[[1000000000001]] — ivvvy 内ページへのリンク（ID表示）

**WikiLink（パイプ記法）：**
[[1000000000001|サンプル一覧]] — ivvvy 内ページへのリンク（カスタムテキスト）

通常の Markdown リンクは外部URLに、WikiLink は ivvvy 内のページ間リンクに
それぞれ適しています。
